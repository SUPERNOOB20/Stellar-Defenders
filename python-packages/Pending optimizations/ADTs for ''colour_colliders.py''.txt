ADTs (Abstract Data Types) that might be helpful to optimise the colour colliders!

* numpy arrays
* structs
* dictionaries (hash tables)

---------------------------------------------------------------

Why do I want to use them?

Reason #1: Performance

The idea is to use arrays: If we allocate a fixed,
invariable amount of storage for the
vertices and triangles, we can implement arrays of them
(instead of lists with variable data size, ew)
to make the game run at a much more healthy
framerate :3


---------------

Reason #2: Organization

Abstract data structures help you visualize stuff a lot
easier, rather than a bunch of random variables
scattered all over the place...


Conclusion and roadmap:

I want to use **numpy arrays** for the collider system in the future!
The idea will be to replace [Vertex(x, y)] by [int, int];
[Triangle(a, b, c)] by [int, int, int],... etc.

(So basically just arrays of ints :3)

This shouldn't be hard to implement but it isn't my focus right now "^^
